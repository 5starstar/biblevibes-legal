Persona Shield (BETA) – Privacy Policy

Effective date: November 10, 2026 (covers version 0.1.13 and later until this page is updated)

Persona Shield (BETA) is a Chrome extension that gives each browser profile one consistent, randomly generated device identity, with optional timezone and WebRTC IP protection and optional advanced canvas and WebGL protection, to reduce cross-site fingerprint tracking. This extension is for beta testing.

What we collect

Nothing. The extension does not collect, transmit, sell, or share any personal information, browsing history, page content, or any other user data. It has no servers, no analytics, no advertising, and sends nothing to us or to anyone else. The only network request it can ever make is the one described under "Web Workers" below, which belongs to an experimental feature that is off by default.

What is stored on your device

The extension saves the following in your browser's local extension storage (chrome.storage.local): the randomly generated device identity it presents to websites, the random numbers (seeds) used for canvas and WebGL protection, and your settings (feature on/off switches, chosen timezone, and options). Chrome also keeps, on the extension's behalf, the page scripts and header rules the extension registers; they are built only from that identity, those seeds and those settings. This data stays on your device, is never sent anywhere, and is deleted when you uninstall the extension.

Why the extension needs access to all websites

Fingerprinting can happen on any site, including embedded frames, so the extension runs on all sites in order to replace device details that pages can read (such as platform, CPU core count, memory, graphics, canvas and audio information and timezone values). It does not record, store or send the content of the pages you visit or the addresses you visit. It also modifies the User-Agent and related Client Hints headers on outgoing requests, and removes the Sec-CH-Device-Memory header, so they match the identity shown to pages. It does not log or store those requests.

What is on by default

After installation these features are on: device information, Client Hints, hardware details, HTTP headers, canvas, graphics (WebGL), audio, hiding Chinese/Japanese/Korean font names, and timezone (see below). WebRTC IP protection, Web Workers, advanced canvas and advanced WebGL are off until you turn them on. Every feature can be switched off in the extension popup, and a master switch turns the whole extension off.

Canvas and graphics (WebGL)

The normal canvas feature adds a tiny, invisible change to the image a website reads back from a canvas. The change is derived from your device identity and the website's address, so you get the same result each time you visit one site, but different sites get unrelated results. The website's address is used only inside the page, to calculate this value; it is not saved or sent anywhere. The normal graphics (WebGL) feature changes the graphics card name that pages can read.

Advanced canvas and WebGL (optional)

These two switches are off by default. If you turn one on, the extension uses Chrome's "User Scripts" feature to run one script, included in the extension, on every page so that it can change canvas images and WebGL pictures by a very small, invisible amount. Chrome only allows this after you switch on "Allow User Scripts" for the extension on Chrome's extension details page; the extension will not turn these switches on until you have done that. The script is a file inside the extension; it is not downloaded from anywhere and the extension does not run any scripts that you or anyone else wrote. Two random numbers (one for canvas, one for WebGL) are saved on your device so the result stays the same each time you start Chrome; they are replaced when you press "New identity". Turning on the advanced canvas switch turns the normal canvas switch off (both change the picture, so they are not meant to run together), and turning the advanced canvas switch off turns the normal canvas switch back on. The normal and advanced WebGL switches do different things (graphics card name versus the picture itself) and can both be on.

While an advanced switch is on (and the master switch is on), the extension keeps one 30-second timer (a Chrome "alarm") that checks whether Chrome still allows User Scripts. If you switched that permission off, the normal canvas feature takes over so your canvas is not left unprotected, and the popup shows a warning. When both advanced switches are off, or the master switch is off, no timer exists. This check uses no network.

If Chrome has User Scripts switched off, the popup shows a button that opens Chrome's own extension settings page for this extension (chrome://extensions), where you can turn on "Allow User Scripts". The button only opens that Chrome page; nothing is sent anywhere.

Font names

The "Hide CJK font names" feature adds a short set of style (CSS) rules to the pages you visit. The rules contain only a fixed list of font names. They reduce what a page can learn about which Chinese, Japanese and Korean fonts are installed on your computer. The feature does not read or store page content.

Timezone

The timezone feature is on by default and reports the US Eastern timezone (America/New_York) to websites. You can choose another timezone from the list in the extension popup or turn the feature off.

Reloading the current tab

When you change a switch, change the timezone, change the Cloudflare or cross-OS options, use the master switch, or press "New identity", the extension reloads the tab you are looking at so the change takes effect. It does not read that tab's content or address for this.

Canvas self-test

The popup has a "Test canvas protection on this tab" button. Only when you press it, the extension draws a small canvas picture and a small WebGL picture in the tab you are looking at, each twice (once as the website would see it, once untouched), compares them, and shows the result in the popup. The popup also shows the address of that tab (cut off at any "?" or "#" and shortened to 80 characters, so no query string or fragment is shown) so you can see which page was tested. The test pictures and the address stay in the popup, are not stored, and are not sent anywhere.

Cloudflare verification

By default the extension leaves frames from Cloudflare's human-verification service (challenges.cloudflare.com) unchanged, so that the verification can complete. In those frames the website sees your real browser details. You can turn this compatibility setting off in the extension popup.

WebRTC IP protection (optional)

If you turn this feature on, the extension asks for the optional "privacy" permission and then sets Chrome's WebRTC IP handling policy so that websites cannot see your real local or public IP address through WebRTC. This may affect video calls. Turning the feature off releases the setting. The extension does not read any other privacy settings.

Web Workers (optional, experimental)

If you turn this feature on, web Workers started by a page show the same device details (and the same canvas change) as the page. In one rare case (a Worker script served with an unusual content type that the browser refuses to load normally) the extension asks once more for that same script address, the address the page itself asked for, so the Worker still runs. That request goes only to the page's own website. Nothing is sent to us and nothing is stored.

Developer debug option

For testing only, if you yourself set the value __ps_debug to 1 in a page's local storage using the browser's developer tools, the extension writes short canvas and WebGL messages (for example which canvas read or shader it handled) to that page's developer console. To know whether you set it, the extension looks at that one key in the page's local storage and no other key. It is off unless you do this. Nothing is stored or sent.

Third parties

None. The extension loads no remote code and contacts no third-party services. The advanced canvas and WebGL methods include open-source code (MIT licence) adapted from the CthulhuJs project by Shawn Li, which is bundled inside the extension; see the THIRD_PARTY_NOTICES file in the extension package.

Changes

If a future version changes how data is handled, this policy will be updated before that version is released.
